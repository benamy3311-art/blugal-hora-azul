# Blu Gal · concepto «Hora azul» (copia de prueba)

Rediseño de prueba para la web de Blu Gal (tatuajes de línea fina, Bogotá). Es una página estática: `index.html` + `assets/`, sin build ni dependencias.

- Ver en vivo: <https://benamy3311-art.github.io/blugal-hora-azul/>
- Variantes de portada: `?portada=fotos`, `?portada=retrato` (por defecto), `?portada=mixto`
- Líneas azules animadas: `?trazo=0` las quita, `?trazo=fin` las deja terminadas
- Esta copia lleva `noindex` (no aparece en Google). Al publicar la web definitiva hay que quitar esa etiqueta y poner la dirección final en `og:image`.
- La barra «Portada · Líneas» de abajo a la izquierda es solo para probar el concepto.
